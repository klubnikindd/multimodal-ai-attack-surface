# Приватность Kadr

Kadr работает локально. Обработка медиа не требует сети, телеметрия по умолчанию
выключена, облачные API не используются.

## Что хранится

- Каталог SQLite: имена/пути файлов, L0-метаданные, теги, эмбеддинги, планы,
  журнал операций, очередь review.
- Кэш превью (если включён) — только локально.
- Логи — без PII и без содержимого медиа; пути редактируются до хэшей/имён.

Каталог создаётся с правами `0600` (файл) и `0700` (каталог) на POSIX; на Windows
действуют ACL пользователя. Каталог не синхронизируется с облаком по умолчанию.

## Что не делается

- Нет автоудаления файлов, авто-перезаписи оригиналов, «улучшения» изображений.
- Нет определения эмоций/расы/пола/возраста/привлекательности.
- Нет LLM-агента с tools (shell/HTTP/ФС) в обработке недоверенных медиа.
- Нет скрытой телеметрии с содержимым файлов.

## Лица (opt-in, experimental)

Лица выключены по умолчанию. При включении — локальная обработка, кластеры без
имён, имена присваивает только пользователь, доступна кнопка «удалить все данные
о лицах». Включение требует проверенной коммерческой лицензии весов; InsightFace
`buffalo_l` запрещён.

## Экспорт

Пресет `stock` по умолчанию удаляет GPS, серийники, лица и PII из тегов/описаний;
`social` дополнительно убирает имена/копирайт; `archive` сохраняет всё. Это
детерминированный фильтр Lite-профиля, а не юридическая гарантия.

## Удаление данных

`kadr` не удаляет оригиналы. «Забыть всё» (P1) удаляет каталог, эмбеддинги, теги и
review; исходные файлы не затрагиваются. Корзина приложения (`~/.kadr/trash`)
хранит созданные копии после undo; её можно очистить вручную.
