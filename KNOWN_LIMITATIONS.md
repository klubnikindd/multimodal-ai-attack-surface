# Known Limitations
- **VLM на CPU медленный:** 10–25 с/кадр; описания ИИ не входят в Lite; на CPU — только явная ночная задача (experimental). Цифры по устройствам — в BENCHMARKS.md.
- **Векторный поиск:** sqlite-vec — brute‑force, комфортная зона до ~50–100K векторов; на больших архивах включается ANN/гибрид или поиск сужается; при недоступности расширения работает только текстовый поиск — статус виден в UI.
- **Лица:** opt‑in, экспериментальны, без имён по умолчанию, полный сброс одной кнопкой; включаются только с проверенными лицензиями весов.
- **SmartScreen/антивирусы:** предупреждения возможны даже с подписью — репутация набирается скачиваниями; публикуем хэши и инструкцию.
- **Даты:** при отсутствии EXIF дата берётся из имени файла или `mtime` — помечается бейджем и уходит в review.
- **Свойства ОС:** xattr/теги теряются на FAT/exFAT и при копировании через некоторые облака.
- **VLM‑описания могут ошибаться:** это подсказка, а не истина; пользовательские теги никогда не перезаписываются.
