# Тестовый мульти-модальный AI Attack Surface

## Описание проекта
Модульный инструмент для анализа поверхности атаки в мульти‑модальных AI‑пайплайнах. Фокусируется на извлечении и проверке метаданных изображений, видео и текста, выявляя потенциальные риски и обеспечивая соответствие требованиям приватности и безопасности.

## Установка
```bash
# Клонирование репозитория
git clone https://github.com//klubnikindd/multimodal-ai-attack-surface.git
cd multimodal-ai-attack-surface

# (Опционально) Создание виртуального окружения
python -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install fastapi pillow uvicorn

# Установка зависимостей для тестов
pip install pytest
```

## Использование

### API
Запуск FastAPI сервера:
```bash
uvicorn attack_surface.api:app --reload
```
Эндпоинт `/metadata` принимает файл и возвращает извлеченные метаданные.

### CLI
```bash
python -m attack_surface.cli путь/к/файлу.jpg
```
Выводит метаданные в JSON.

## Архитектура
Ключевые модули находятся в пакете `attack_surface/`:
- `metadata.py` – логика извлечения метаданных из изображений, видео и текста.
- `api.py` – FastAPI приложение.
- `cli.py` – точка входа для CLI.

Подробности проектирования: `docs/spec/v3.md` и архитектурные решения – `docs/ADR-*.md`.
