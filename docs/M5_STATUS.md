## Заблокировано

### Спайк D (замеры на целевом железе)
Текущая машина (28 ядер + дискретная GPU) **нерепрезентативна** для целевых
профилей. Нужны замеры на:
1. **4-ядерный / 8-ядерный CPU** — VLM 2B (мс/фото), ASR;
2. **Apple Silicon** (M1+) — VLM;
3. **VLM 4B** (только Pro) — замер.

Как только появятся замеры — внести в `device_bench` + `docs/BENCHMARKS.md`.
