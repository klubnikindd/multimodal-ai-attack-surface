# Оригиналы внешних ревью

Здесь хранятся первоисточники ревью, на которые ссылается ТЗ (разделы
§20 «Трассировка v2 → v3» и §21 «Трассировка v3 → v3.1»).

## Ожидается

| Файл | Что это | Статус |
|---|---|---|
| `pravki-2026-11-13.md` | внешнее ревью v2 (5 подтверждённых замечаний + 5 стратегических рекомендаций), основание правок v3 | **отсутствует** |

## Почему это важно

§20 спеки — реконструкция замечаний по цитатам. Пока оригинал не приложен:

- связки «замечание → решение» проверяемы только по тексту самого §20;
- нельзя подтвердить, что все замечания разобраны (нет первоисточника);
- `docs/spec/v3.1.md` §20.0 фиксирует это честно, а не выдаёт реконструкцию за источник.

## Как добавить

1. Положить файл в эту папку под именем `pravki-YYYY-MM-DD.md` (дата ревью).
2. Убрать из него персональные данные ревьюера, если они не предназначены для публикации.
3. В `docs/spec/v3.1.md` §20.0 заменить оговорку на ссылку: `docs/reviews/pravki-2026-11-13.md`.
4. Проверить, что `scripts/check-spec-invariants.py` остаётся зелёным.
