# ADR-0001: Дистрибуция — Tauri 2 + Python-sidecar, нативные установщики

- **Статус:** принято (2026-11-12)
- **Контекст:** продукт пойдёт «в массы», пользователям без технической подготовки. Исходное ТЗ предлагало Docker как способ кроссплатформенности и PyInstaller как способ сборки.
- **Решение:** оболочка на **Tauri 2** (системный webview) + движок на Python 3.12, упакованный как **sidecar-бинарь**; нативные установщики `.msi` / `.dmg` / `.AppImage`+`.deb`+`.rpm`. ML-рантайм: **ONNX Runtime** (CPU/DirectML/CoreML) для лёгких моделей и **встроенный llama.cpp** (GGUF) для VLM. **Ollama — опциональное подключение внешнего сервера, не зависимость.** Docker остаётся для разработки, CI и опционального NAS-режима (P2).

## Рассмотренные альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Docker-first | одно окружение, легко воспроизводить исследователям | WSL2/виртуализация, права админа, overhead RAM, образ 5–10 ГБ, **нет Metal на macOS**, нет интеграции с ОС, платная лицензия Docker Desktop для части компаний | целевая аудитория не пройдёт установку |
| PyInstaller + pywebview | всё на Python, быстрее всего сделать | 300–800 МБ, ложные срабатывания антивирусов, ручные подпись/updater, хрупкие сборки ML | остаётся запасным путём, если M0-спайк Tauri провалится |
| Electron + sidecar | предсказуемый рендер | +150–250 МБ, RAM | размер не оправдан для нашего UI |
| Tauri + Rust + ONNX (без Python) | минимальный размер, максимум скорости | ML-экосистема на Rust беднее, переписывание пайплайнов | цель v1.0, не v0.1 |

## Последствия

**Положительные:** установщик ≤ 60 МБ без моделей; нативные меню/трей/drag&drop/корзина; подписанный автообновлятор; GPU-ускорение на всех ОС; отсутствие обязательных внешних сервисов; Engine остаётся usable как CLI/локальный сервер (тесты, research, будущий NAS).

**Отрицательные / затраты:** два языка (Rust + Python) и связка lifecycle; нужен M0-спайк «пустой sidecar под 3 ОС»; подпись Windows (Azure Artifact Signing ≈ $9.99/мес, для физлиц только США/Канада; иначе OV $150–300/год) и Apple Developer $99/год + нотаризация; репутация SmartScreen набирается скачиваниями.

## Обязательные технические условия

1. Engine биндится **только на 127.0.0.1**, случайный порт, bearer-токен через IPC-handshake; проверка `Origin`/`Host`. Dev-конфиг (`0.0.0.0`) не может попасть в релиз — CI-проверка.
2. Оболочка гарантированно завершает sidecar и воркеров при выходе; перезапуск при краше с уведомлением; никаких «висящих» процессов.
3. Модели не в установщике: менеджер загрузок с возобновлением, sha256, зеркалом и оффлайн-бандлом.
4. Сборка релиза — только в CI, с подписью, SBOM и лицензионным гейтом.

## Проверка решения

M0-спайк: пустой Tauri-оболочка + Python-sidecar собирается и запускается на Windows 11, macOS 14 (arm64), Ubuntu 22.04; установка → окно → API отвечает ≤ 5 с; корректное завершение процессов. Если спайк не проходит за отведённое время — переходим на запасной вариант (PyInstaller + pywebview) без изменения доменного кода.
