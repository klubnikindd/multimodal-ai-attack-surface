# ADR-0007: UI-фреймворк — React + TypeScript + Vite

**Статус:** принято (2026-11-21) · **Связано:** ТЗ v3.1 §6.2, §18.6

## Контекст

ТЗ §6.2 оставляло выбор «Svelte/React» до M0; открытый вопрос §18.6 блокировал
M0-гейт, M4 и M6 (P1-07 плана).

## Решение

UI-оболочка — **React 18 + TypeScript + Vite** внутри Tauri 2.

## Обоснование

1. **Зрелая экосистема виртуализации и таблиц** для галереи на 200K+ файлов
   (react-window / TanStack Virtual, TanStack Table) — критично для NFR-01/03 и
   FR-5.1 (галерея, фасеты, review inbox).
2. **Наибольшая база компонентов** для медиа-каталога (image viewer, drag&drop,
   форм) — сокращает срок M4.
3. **Низкий порог входа** для контрибьюторов (Svelte 5 — тоньше экосистема для
   сложных виртуализированных гридов).

## Альтернативы

- **Svelte 5**: меньше бандл и проще реактивность, но тоньше экосистема для
  виртуализированных медиа-гридов — отклонено для v0.1.

## Последствия

- ui/ — Vite + React + TS; src-tauri/ — Rust-хост.
- Положительное: ускоряет M4 (каталогизатор), снижает риск NFR-03/10.
- Отрицательное: чуть больше размер бандла против Svelte (в бюджете NFR-07 это
  не критично — модели вынесены отдельно).
