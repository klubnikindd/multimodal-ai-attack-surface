# Политика безопасности и ответственное раскрытие

Kadr обрабатывает недоверенные медиафайлы из чужих рук, поэтому безопасность —
часть продукта (см. `docs/THREAT_MODEL.md`), а не только research-трек MIAS.

## Как сообщить об уязвимости

Не создавайте публичный issue с payload'ом, который эксплуатирует уязвимость.
Используйте приватный канал GitHub Security Advisory или напишите владельцу
репозитория `klubnikindd/multimodal-ai-attack-surface`.

В сообщении укажите:

- версию/коммит, ОС, профиль, бэкенд индекса;
- воспроизведение (файл-пример или генератор, без чужих персональных данных);
- ожидаемое/фактическое поведение, влияние, остаточный риск;
- была ли включена песочница/нативные условия.

## Сроки

- Подтверждение получения — 3 рабочих дня.
- Первичная оценка — 7 рабочих дней.
- Исправление/митигация — по критичности; критические (RCE, path traversal,
  потеря оригиналов, утечка PII) — приоритет P0.
- Публичное раскрытие — после исправления и согласования; в `SECURITY_NOTES.md`
  добавляется разбор с указанием ОС, на которой получен результат.

## Safe harbor

Исследование на собственных данных/с разрешения владельца архива, без атак на
инфраструктуру и без доступа к чужим данным, не будет преследоваться.

## Запрещено

- Публиковать security-метрики, полученные только в Docker, как продуктовые.
- Прикладывать реальные персональные данные/медиа в issue.
- Тестировать на чужой библиотеке без явного согласия.
