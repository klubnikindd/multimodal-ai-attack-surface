# Scale-тесты векторного поиска (спайк E, §13.1 v3.1)

Харнесс: `bench_scale.py` — синтетические нормализованные векторы,
recall@10 против точного перебора (numpy), p95 латентности, время сборки,
размер каталога. Идентификаторы устройств — через `KADR_BENCH_DEVICE`.

## Как запускать

```
python tests/scale/bench_scale.py --vectors 50000 --backend sqlite-vec --queries 20
python tests/scale/bench_scale.py --vectors 200000 --backend ann
python tests/scale/bench_scale.py --matrix --queries 20 --markdown
```

Матрица `--matrix`: 10K/50K/100K/200K/500K × (sqlite-vec до 100K, ann). `hybrid` и
`brute-force` — точечно, это Python-перебор (эталон точности, не скорость).

| 50K | измерено (2026-11-20) | измерено | — | — | Ф1 |
| 100K | измерено (2026-11-20) | измерено | — | — | Ф1 |

| 500K | ☐ | ☐ | ☐ | — | Ф1 (длительный прогон) |

Результаты заносятся в `docs/BENCHMARKS.md` (строки «не измерено» заменяются
фактами — правило §8.3). Порог переключения бэкендов
(`factory.auto_backend`, 50K/100K) пересматривается по факту в ADR-0004.
