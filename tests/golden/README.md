# Golden-датасет (M2, P3-03)

Протокол — v3.1 §13.2.1. **Файлы датасета НЕ хранятся в git** (LFS или внешний
бакет); в репозитории — только `manifest.json` (хэши, лицензии, source) и
харнесс метрик `tests/golden/eval_quality.py`.

## Состав (нормативно, §13.2.1)

- 500–1000 файлов; ≥40% «трудных» (без EXIF, битые даты, HEIC/RAW, burst,
  скриншоты, документы, 2–3 коротких видео); ≥10% adversarial из
  `security/corpus`.
- Разметка: сцена, событие, «уместная папка», качество кадра, дубли
  (точные/почти), «злые» файлы. Размечает владелец продукта, вслепую к выводу.
