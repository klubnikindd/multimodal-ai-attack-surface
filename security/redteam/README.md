# Red-team генераторы (MIAS)

Здесь будут генераторы payload'ов: EXIF/XMP-инъекции, типографские атаки,
path traversal, malformed-файлы, XSS. В v0.1 реализованы детерминированные
детекторы и регрессии в `tests/kadr/`; генераторы PGD/TTA и fuzz — M3.

Ограничения: только собственные/разрешённые материалы, без PII и чужих фото.
